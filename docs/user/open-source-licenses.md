# Open source licenses

Tung Tung Tung Code includes third-party software and adapted assets. To read their license and attribution
notices:

- On web and desktop, open **Settings → About**, find **Open source licenses** under **Legal**,
  and select **View licenses**.
- On mobile, open **Settings → About Tung Tung Tung Code → Open source licenses**.

The page lists the version when available, license identifier, and the parts of Tung Tung Tung Code that include
or use the item. This also covers optional device tools that Tung Tung Tung Code installs on demand instead of
bundling. Select a row to read the complete notice text. Use the search field to find a package,
version, license, or app component.
